ADDING REAL FILES
-----------------
1. Create folders under /resources/, for example:
   resources/class-6/science/

2. Add your PDFs.

3. Edit data/resources.js and replace:
   "href": "#"

   with a real path such as:
   "href": "resources/class-6/science/Class6_Science_FA1_QP.pdf"
